# Transcript → JSON (for Interview Annotation Tool)

Open `transcript-to-json-tool/index.html` in your browser and paste your transcript on the left.

## Input format

One utterance per line:

```
{speaker}: {utterance}
{speaker}: {utterance}
...
```

Empty lines are ignored.

## Output

Downloads a JSON file named `transcript.json` that can be loaded in `interview-annotation-tool/index.html` using **Open**.
